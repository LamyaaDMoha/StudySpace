## About the Project

StudySpace is a web-based study planner designed to make studying more organized and productive.

The website provides a simple dashboard where students can manage their study tasks, check their progress, and use a customizable focus timer.

## Project Purpose

I created StudySpace as my final project for the Pathy program to apply what I learned throughout the course.

My main goal was to practice using Git and GitHub in a real project, including creating repositories, working with branches, making commits, opening pull requests, and merging changes.

I also used this opportunity to improve my HTML, CSS, and JavaScript skills by building a simple and interactive website.

## Features

- Add, complete, and delete study tasks.
- Track completed tasks and overall progress.
- Save tasks automatically using local storage.
- Use a focus timer with Start, Pause, and Reset controls.
- Choose between 15, 25, 45, and 60-minute sessions.
- Set a custom focus duration.
- Use the website on different screen sizes.

## Technologies Used

- HTML
- CSS

- GitHub Pages

## How to Use

1. Open the StudySpace website.
2. Enter a study task and click "Add Task".
3. Mark tasks as completed when finished.
4. Check your progress on the dashboard.
5. Select a focus timer duration.
6. Click "Start" to begin studying.
7. Use "Pause" or "Reset" when needed.
